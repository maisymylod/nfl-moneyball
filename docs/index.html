Draft surplus value

Drafts 2021–2025, skill positions only. Realized is each player's current-season production above the per-position model's expectation (the same production_residual the bargains tab uses). Expected is a robust log-linear fit of realized residual vs draft slot across the cohort. Surplus = realized minus expected: positive means the pick outperformed the typical outcome at that slot, negative means it under-performed. Players not in the current rankings (cut, retired, injured, never qualified) keep NaN surplus rather than being imputed to zero.
